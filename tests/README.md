# Tests: oracle rows

Oracle = Python supervision (`.work/oracle-venv`, editable install of `.work/supervision-develop`).
Rows are generated by `tools/gen_*.py`, stored in `tests/cases/*.txt` (numeric and metric ops) and
`tests/fixtures/` (datasets, pixel references). Every Mojo test binary is built to `build/<stem>`.

## Row file

- Line 1 is the generator header: `# gen: tools/<gen>.py seed=<n>`.
- Lines starting with `#` are comments; blank lines are skipped.
- One case per line, three tab-separated columns:

      <op>\t<args JSON>\t<expected JSON>

- Arrays are nested JSON lists. NaN is written as the string `"nan"`.
- Floats compare with abs + rel tolerance 1e-6 (`|a-b| <= 1e-6 + 1e-6*|b|`) unless the row's
  args carry `"tol": {"abs": x, "rel": y}`.
- Pixel and file rows: args = `{"input": "<fixture path>", "params": {...}, "tol": {"max_abs": n, "max_pct": p}}`;
  expected = `{"ref": "<fixture path>"}`. The binary prints `{"out": "<produced file>"}`.
  Images are compared by `tools/pixdiff.py` (max abs channel diff, percent of differing pixels).
  Non-image refs are compared byte-for-byte with `cmp`. Missing `tol` means byte-exact (0, 0).
  The bar lives in the row and is never loosened to pass.

## Binary contract

`tests/run.sh <file>` takes the row file, feeds its case lines (comments and blanks removed) to
`build/<file stem>` on stdin, and expects exactly one JSON line on stdout per row, in row order.
`tools/rowdiff.py` then compares each line with the expected column.

## Running

    tests/run.sh                        # every tests/cases/*.txt
    tests/run.sh tests/cases/x.txt      # one file
    tests/selftest.sh                   # the harness itself (stub binaries, no Mojo build)

Output: `PASS <file>:<line>` or `FAIL <file>:<line> <op>: <reason>`, then `SUMMARY`.
Exit non-zero on any FAIL, a missing binary, a binary crash, or a row/output count mismatch.
A missing binary is a FAIL, never a skip. With zero row files the run prints `SUMMARY 0 row files`
and exits 0.

## Generators

`tools/oracle.py` provides `row()`, `write_rows()` and `check_oracle()`. Run generators with the
venv: `.work/oracle-venv/bin/python tools/gen_<x>.py`. Each generator states its seed in the header.
