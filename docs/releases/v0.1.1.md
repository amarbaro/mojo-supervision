# mojo-supervision v0.1.1

**Released:** 2026-11-12 · **Commit:** tag `v0.1.1` · **Previous:** [v0.1.0](v0.1.0.md)

## What it does

Roboflow [supervision](https://github.com/roboflow/supervision) ported to Mojo. Every op is checked
against Python supervision on the same inputs: 3308 recorded rows pass.

```mojo
from supervision.detection.utils.iou_and_nms import box_iou, box_non_max_suppression


def main() raises:
    var xyxy: List[Float64] = [0, 0, 10, 10, 1, 1, 11, 11, 50, 50, 60, 60]
    var scores: List[Float64] = [0.9, 0.8, 0.7]
    var cats: List[Int] = [0, 0, 0]
    print(box_iou([0.0, 0, 10, 10], [1.0, 1, 11, 11]))   # 0.680672268907563
    var keep = box_non_max_suppression(xyxy, scores, cats, 0.5)
    for k in keep:
        print(k)                                           # True False True
```

Runnable copy: `examples/quickstart.mojo`.

## Highlights

- Installable as a conda package: `pixi add mojo-supervision` pulls mojo-cv, mojo-gzip and mojo-json with it.

## Changes

### Changed
- The 12 dataset command-line drivers moved from `src/supervision/dataset/` to `src/drivers/` (Mojo refuses `main()` inside a package, so `mojo precompile src/supervision` failed). Build them with `mojo build -I src -I <mojo-json>/src src/drivers/<stem>.mojo`.
### Fixed
- `pyproject.toml` declares the library dependencies (`[tool.mojo] deps`) and one compiler range, so the generated recipe has them as host and run requirements.
